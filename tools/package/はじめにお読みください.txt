ProRes Player
==============

Windows 用の ProRes 確認プレイヤーです。ProRes のほか、mp4 / mkv / avi / webm / mxf なども再生できます。

■ インストール
  1. この zip をすべて展開する（zip の中から直接実行しない）
  2. install.cmd をダブルクリックする
     - %LOCALAPPDATA%\Programs\ProResPlayer にインストールされます
     - スタートメニューに「ProRes Player」が追加されます
     - .mov などの「プログラムから開く」に ProRes Player が追加されます
     - 管理者権限は要りません。.NET などを別に入れる必要もありません

  .mov を既定で ProRes Player で開くには：
     .mov を右クリック →「プログラムから開く」→「別のプログラムを選択」→ ProRes Player →「常に使う」

■ アンインストール
  uninstall.cmd をダブルクリックする

■ 主な操作
  Space            再生 / 一時停止
  ← / →            1フレーム戻る / 進む
  シークバー        クリックで移動、ドラッグでスクラブ
  Ctrl+← / →       同じフォルダの前 / 次の動画（PageUp / PageDown でも可）
  1 2 3 4          背景：市松模様 / 黒 / 白 / アルファのみ
  I / O / P / L    ループ開始 / 終了 / クリア / ループ オン・オフ
  C                比較：オフ → 左右 → ワイプ
  Ctrl+S / Ctrl+C  今のフレームを PNG で保存 / コピー
  Tab              情報パネル
  F                全画面
  その他はメニューの「ヘルプ」→「ショートカット一覧」

■ ライセンス
  再生エンジンに libmpv / FFmpeg（GPL / LGPL）を使っています。
